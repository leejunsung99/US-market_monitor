# 중요도 3단계 분기 시안

2026-10-22 사용자 요청: 명확한 사건은 규칙으로 바로 통과, 애매한 내용만 LLM 재검토, 명확한 제외 대상은 즉시 제외. 입출력 레이아웃 변경과 분리한다.

## 분기

| 경로 | 대상 | LLM 중요도 호출 |
|---|---|---|
| pass | 구체적인 사건 규칙을 통과한 중요 발표 | 없음 |
| llm_review | 기존 검토 후보, 해석 중심 동향/일반 발표, 관련성이 있지만 규칙이 놓친 후보, 실적 예고처럼 오탐 가능성이 있는 기사 | 한 번 |
| reject | 광고·라이프스타일·과거 기사·잘못된 출처, 관련성/사건 단서가 없는 기사 | 없음 |

단순히 기존 필터 뒤에 LLM을 붙이지 않는다. 기존 탈락 기사 중 기업·산업·경제 관련 단서와 수치/관련 주체가 있는 후보도 llm_review로 승격한다. 다만 모든 무관 기사를 LLM에 보내지는 않는다. 기존 rules YAML이나 운영 classifier 자체를 느슨하게 변경하지 않고 별도 모듈로 시험한다.

LLM은 alert / ignore / uncertain, 짧은 한국어 이유, 근거 문장 ID만 반환한다. 긴 번역이나 요약을 함께 생성하지 않는다. alert에도 실제 인용 ID가 필요하다. 출력 형식/인용 ID 검사는 의미의 정확성을 완전히 보장하지 않으므로, 본 채널 적용 전 내용 평가가 필요하다. uncertain, 시간 초과, 형식 오류는 보류하며 자동 통과시키지 않는다.

## 현재 구현 범위

- `processors/hybrid_filter.py`: 기존 classifier를 원본 복사본에 적용해 중요도를 3단계로 분기. 입력 이벤트와 기존 규칙을 변경하지 않는다.
- `scripts/review_hybrid_filter.py`: 운영 DB 읽기 전용 재생. 승인 이벤트와 review_candidates 발췌를 재검토한다.
- 후보 입력·모델·정책 버전의 해시로 LLM 결과를 캐시한다. 같은 자료를 반복 판정하지 않는다. 실패·보류 캐시도 입력 또는 버전이 바뀌기 전까지 유지한다. 자동 재시도는 구현하지 않았다.
- 한 번 실행에서 LLM 검토 건수를 제한한다. 기본은 0건이며 최대 10건이다.
- 보고서와 캐시: `data/hybrid-filter/`. 보고서 발송은 테스트 채널만 허용한다.

현재는 과거 자료 재생 시안이며 운영 scheduler에는 연결하지 않았다. 실제 적용 시에는 기존 중복/기발송 검사를 먼저 수행하고, LLM 검토를 별도 제한된 작업 대기열에 넣어 직접 통과한 알림을 지연시키지 않도록 해야 한다. 승인 뒤에도 기존 알림 중복 검사를 다시 거쳐야 한다. 오래된 보류 후보를 무조건 발송하면 안 된다.

보존 이벤트는 이미 승인되었던 자료이고 검토 후보는 일부 발췌만 남는다. 이 재생 결과의 분기 비율을 전체 실시간 입력의 LLM 호출 비율로 해석하면 안 된다. 탈락 원문이 저장되지 않은 과거 기사의 누락을 전부 측정할 수 없다.

```powershell
# 분기 분석만 (LLM/발송 없음)
.\.venv\Scripts\python.exe scripts/review_hybrid_filter.py
# 최근 애매한 후보 최대 3건을 GPU LLM으로 판별
.\.venv\Scripts\python.exe scripts/review_hybrid_filter.py --judge-limit 3
# 캐시된 판정을 포함한 결과를 테스트방에 보고 (본 채널 발송 없음)
.\.venv\Scripts\python.exe scripts/review_hybrid_filter.py --judge-limit 3 --send-report
```

운영 적용 전에는 직접 통과 오탐, LLM 승인 오탐·누락, 보류율, 캐시 재사용, 초당 유입량 대비 대기 시간을 함께 확인해야 한다.

## 이번 재생 시험

보존 이벤트·검토 발췌 총 132건에서 직접 통과 45건, LLM 검토 후보 70건, 제외 17건으로 분기했다. 이 중 최근 검토 후보 3건만 실제 GPU 모델에 전달했다.

- Nebius 용량 할인 프로그램 기사: 모델 ignore, 첫 호출 50.62초.
- 테슬라 연간 capex 전망 $20B 하향 기사: 모델 alert, 11.09초. 주가 등락이 있는 제목이어도 구체적인 전망 변경이 있으면 후보로 복구했다.
- 메타 지표 비교 기사: 구체적인 숫자/새 사실이 부족하다는 이유로 모델 ignore, 9.56초.

위는 모델의 시험 판정이며 3건만으로 정확도를 검증한 결과는 아니다. 첫 호출의 로딩을 포함한 시간과 준비된 모델의 판정 시간을 구분해야 한다. 근거 ID 존재 검사는 모델이 근거 문장을 정확하게 해석했는지까지 보장하지 않는다.

두 번째 실행에서는 세 판정을 캐시에서 재사용했다. 테스트방 메시지 129로 보고서 발송 완료. Ruff 및 전체 pytest 277개 통과. 본 채널 운영 경로는 변경하지 않았다.
