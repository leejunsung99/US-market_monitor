# 사진과 함께 보내는 압축 알림 — 2026-10-28 검토안

> 이후 사용자가 본 채널 적용과 최근 긴 알림 10건 수정을 승인했다. 아래는 최초 검토 기록이며, 승인 후 운영 변경은 [PHOTO_CAPTION_PRODUCTION.md](PHOTO_CAPTION_PRODUCTION.md)에 기록한다.

이번 요청은 NVIDIA CPU 사업 알림(event 159)을 다시 구성해 테스트 채널에서 확인하는 범위다. 운영 프로세스는 재시작하지 않았고, 기존 본 채널 알림도 수정하지 않았다. 새 형식은 `caption_brief` 메타데이터가 있는 알림에만 적용한다.

선별 기준은 회사의 새로운 사업 변화, 실제 실적, 경영진의 수치 전망, 고객 도입·출하, 공급·재무 제약이다. 단순 경쟁사 소개, 기존 협력 관계 설명, 주가 등락 이력, 목표주가와 매수 의견, 반복된 사실은 제외한다. 제목은 주된 회사와 짧은 주제로 구성하고, 핵심내용·주요 실적·향후 전망·주요 위험을 구분한다.

각 항목은 원문 문장 ID 하나, 짧은 한국어 문구, 강조할 부분 문자열, 중요도 순서로 정의한다. 강조 문구는 본문의 정확한 부분 문자열이어야 한다. 원문 근거·금액 단위·기간·예상과 실적 구분을 검증한 뒤 애플리케이션이 HTML을 만든다. 외부 문자열이 서식 태그로 삽입되지 않도록 이스케이프한다.

완성된 제목·본문·원문 링크·채널 링크를 합쳐 UTF-16 표시 길이 1,024 이내로 제한한다. 원문 링크는 전체 URL을 표시하며 줄이거나 ‘기사 원문’ 같은 대체 문구로 숨기지 않는다. 표시된 URL 길이도 예산에 포함한다. HTML 태그와 링크 목적지 속성은 표시 길이에서 제외한다. 한도를 넘으면 중요도가 낮은 항목 전체를 제외하며, 문장·수치·조건·URL을 중간에서 자르지 않는다. Telegram 전송에서도 같은 길이 계산을 사용하므로 굵은 글씨 태그 때문에 사진과 본문이 분리되지 않는다.

NVIDIA 예시는 기존 한국어 요약을 그대로 재사용하지 않고 보관된 영문 원문과 대조해 다시 작성했다. 로컬 모델의 첫 압축 초안은 다른 문장의 EPS·연도를 섞어 검증에 실패했으므로 사용하지 않았다. 최종 기록의 provenance는 `source-verified-editorial`로 명시했다. 자동 압축 모델은 운영에 연결하지 않은 검토용 구현이며, 이번 예시의 검증 성공을 모든 기사 자동 압축의 검증으로 간주하지 않는다.

최종 예시는 8개 항목, 표시 길이 371 UTF-16 단위, HTML 문자열 670자다. 테스트 채널 메시지 163에서 사진과 캡션이 한 메시지로 전송됐고, 실제 응답의 사진 목록·캡션·굵은 글씨 엔티티를 확인했다. `CPU 매출 두 배 이상 증가 예상` 부분이 실제 bold 엔티티로 들어 있다. 검증 자료와 원본 기사 이미지는 `data/caption-preview-20261028/`에 보관한다.
