# 사진과 함께 보내는 압축 알림 운영

2026-10-28 사용자 승인에 따라 신규 기사 준비 단계를 `CaptionProcessor`로 전환한다. 제목과 카테고리는 굵게·밑줄, 본문은 한국어 개조체, 핵심 표현은 굵게 표시한다. 기사 원문 URL과 `https://t.me/growth_us`를 모두 전체 주소로 표시한다.

새 사업 변화, 실제 실적, 경영진 전망, 고객 도입·출하, 구체적 위험을 우선한다. 경쟁사·회사 소개, 과거 주가, 목표주가·매수 의견, 광고, 반복 정보는 제외한다. 발표 전 전망과 잠정 실적을 확정 실적으로 표시하지 않는다. 제목에 뒤늦게 등장한 협력사를 주된 회사로 오인하지 않도록 제한한다.

로컬 Ollama가 먼저 중요한 원문 문장 ID를 선택한 뒤 문장 하나씩 요약·번역한다. 금액 등 숫자 토큰을 보호·복원하고 근거 ID·수치·규모·기간·실적 상회/하회·한국어 여부를 검사한다. 실패 항목만 재시도하며 검증된 항목은 `caption_work`로 보존한다. 검증 실패나 영문 초안은 발송하지 않는다. 강조 문구는 검증된 한국어 문구의 실제 부분 문자열에서 선택한다.

제목·카테고리·본문·전체 링크·채널 안내를 합쳐 표시 길이 1,024 UTF-16 단위 이내로 제한한다. HTML 태그는 표시 길이에서 제외한다. 중요도 순서로 항목 전체를 넣으며 넘치는 항목은 제외한다. 문장·숫자·URL 중간을 자르지 않는다. 이미지가 있으면 사진과 캡션을 한 메시지로 보낸다. 이미지 URL을 Telegram이 거절하면 같은 요약을 텍스트로 보낸다.

최근 발송분에서 표시 길이 500자를 넘는 최신 10건(event 163, 162, 161, 160, 159, 157, 155, 152, 149, 144)을 원문과 항목별로 대조해 편집했다. 기존 본 채널 사진 캡션을 수정하고, 확인 후 분리된 본문 7개를 삭제했다. 기존 이미지는 유지했다. 전체 링크를 포함해 335~507 표시 단위다. 이력 편집은 `source-verified-editorial`로 표기하여 자동 생성과 구분했다.

DB 백업·원문별 편집본·작업 명세·Telegram 편집/삭제 확인은 git 제외 경로 `data/caption-rollout-20261028/`에 보관한다. 최초 NVIDIA 검토본은 `data/caption-preview-20261028/`에 별도로 보관한다.
