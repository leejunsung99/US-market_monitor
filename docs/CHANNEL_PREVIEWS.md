## 최신 출력 양식

실적이 실제 발표된 자료의 제목은 `🇺🇸메타(META) | 실적발표 요약🇺🇸` 형태로 표시한다. 발표 전 예상·예고 기사에는 `실적발표`를 사용하지 않는다.

어닝콜·경영진 설명 자료는 `🇺🇸메타(META) | 어닝콜 요약🇺🇸`로 구분한다. 사용자는 어닝콜에도 실적 수치 반복 표시를 원한다. `핵심내용 → 주요 실적 → 경영진 발언 → 향후 전망`을 내용이 있는 구역만 표시한다. 실제 Q&A나 음성이 없는 자료에서 이를 만들어 넣지 않는다. 현재 메타 예시는 어닝콜 하이라이트 기사 기반이며 원음 처리 결과가 아니다.

실적 발표와 어닝콜은 같은 회사·회계연도·분기의 서로 다른 단계로 연결한다. 수치가 겹친다는 이유만으로 어닝콜을 차단하지 않되, 동일 어닝콜을 재포장한 기사는 중복 차단할 대상이다. 이 단계별 중복 정책은 운영 적용 전 설계이며 현재 본 채널의 중복 로직을 변경한 것은 아니다.

제목 양쪽 국기는 미국 국기 🇺🇸를 사용한다. 제목과 카테고리는 Telegram HTML의 `<b><u>...</u></b>`로 굵게·밑줄 표시한다. `📍핵심내용` 뒤에 실제 내용에 맞춰 `📍주요 실적`, `📍주요 계약·투자`, `📍사업 진행 상황`, `📍향후 전망`, `📍참고사항` 등을 이어 붙인다. 없는 정보는 빈 카테고리로 만들지 않는다. 본문 항목은 `·`로 표시한다. 하단은 원문 링크와 `🇺🇸그로쓰리서치 U.S 채널[실시간 U.S 주요 알림]`, `https://t.me/growth_us` 순서다. 모델명·처리 시간은 시안 본문에서 제외한다.

### 수치·문체 최신 지침

- 금액·수준 자체에 증감 부호를 붙이지 않는다. `매출: 646.01억 달러 (전년 동기 대비 +26%)`처럼 증감률 앞에 증가 `+`, 감소 `-`를 표시한다. 비교값이 없는 이익률 수준은 `52.4%`로 유지한다.
- `매출 증가·영업이익 감소`, `로보택시 서비스 개시`처럼 명사형 목록을 사용한다. 한 항목에 서로 다른 두 지표를 연결하지 않고 각각 줄바꿈한다.
- `공시 기준`, `비교 기준` 같은 추출 과정 설명은 알림에서 생략한다. 전년 동기/직전 분기, GAAP/non-GAAP, 단위처럼 의미 해석에 필요한 기준은 수치 옆에 표시한다.
- 실제 관련 이미지는 첨부하며 로고·광고·무관 이미지는 제외한다.

최근 5건의 최신 시안 발송: `scripts/send_recent_compact.py --send` (별도 테스트 채널만 허용). 이전 메타 단일 예시는 `scripts/send_compact_preview.py`에 남아 있으며 최신 명사형 수정은 최근 5건 시안이 기준이다.

- 본 채널 `@growth_us`: 기존 실시간 수집·필터·발송 경로 유지.
- 테스트 채널: `.env`의 `TELEGRAM_TEST_CHAT_ID` 사용.
- 레이아웃과 요약 구조를 조정하는 동안 시안은 테스트 채널에만 발송한다.
- 본 서비스 적용은 사용자가 요청한 뒤 진행한다. 시안 확인을 위해 운영 프로세스를 재시작하거나 운영 DB의 전송 이력을 변경하지 않는다.

## 테슬라 실적 시안

`scripts/preview_tesla_earnings.py`는 2026년 3분기 특정 SEC 첨부자료를 기반으로 만든 편집 시안이다. 일반 실적 자동화에 연결된 모듈이 아니다.

회사명(테슬라)을 먼저 쓰고 티커(TSLA)는 괄호로 표시한다. 핵심 실적, 사업별 매출, 사업 진행 상황, 비교 기준, 원문 순으로 구성한다. 전년 동기 비교와 GAAP/non-GAAP를 구분한다. 분기·단위·필수 행이 확인되지 않으면 발송하지 않는다.

```powershell
# 로컬 시안 생성만
.\.venv\Scripts\python.exe scripts/preview_tesla_earnings.py
# 테스트 채널에만 발송
.\.venv\Scripts\python.exe scripts/preview_tesla_earnings.py --send
```

생성 파일: `data/tesla-earnings-test-preview.html`. 이 스크립트에는 본 채널 발송 옵션이 없다.
