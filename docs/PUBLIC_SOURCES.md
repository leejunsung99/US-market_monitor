# 무료 공식 출처와 알림 범위

2026-10-15 설정. 사용자가 선택한 범위는 **연결된 채널의 공식 발표를 폭넓게 알림**입니다.

## 연결된 출처

| 출처 | 수집 범위 | 기본 간격 |
|---|---|---|
| BLS | CPI·PPI·고용·실업률·JOLTS | 2분 |
| BEA | 전국 GDP·개인소득/소비/PCE | 2분 |
| Census | 소매판매·내구재·주택 등 공식 RSS의 18개 지표 | 2분 |
| DOL | 주간 신규·계속 실업수당 공식 PDF | 10분 |
| EIA | 주간 원유·휘발유·정제유 재고 공개 CSV | 30분 |
| 상무부 BIS | 수출규제와 집행 등을 포함한 보도자료 | 10분 |
| 공식 뉴스룸/IR | NVIDIA·AMD·Intel·Qualcomm·Apple·Google·TSMC | 10분 |
| Census 일정 | 해당 연도 공식 일정에서 수집 가능한 발표 | 6시간 |

기존 연준·SEC·Finnhub 수집은 유지합니다. 별도 유료 데이터 가입이나 API 키는 추가하지 않았습니다. 회사별 주소와 허용 호스트는 `settings/official_sources.yaml`, 공통 설정은 `.env`에 있습니다.

## 적용한 필터

- BLS·BEA·Census·DOL·EIA는 지표 종류와 공식 URL을 확인한 실제 발표만 수집합니다. 예상치·컨센서스·시장 반응을 생성하지 않습니다.
- `OFFICIAL_ALERT_SCOPE=all`: 검증한 경제·정부·연준 발표는 폭넓게 받습니다. 기업 뉴스룸은 공식 출처여도 실적·전망·대규모 계약/투자·핵심 제품 등 중요 사건 기준을 충족해야 합니다. 단순 행사·홍보 글은 자동 승인하지 않습니다.
- 할로윈·패션 트렌드, 디자이너의 기기 활용 사례, 사용 팁 등 생활·활용 콘텐츠는 제목 단계에서 제외합니다. 본문에 제품명이나 기술 용어가 있어도 이 제외 기준이 우선합니다.
- 전년 대비 비교가 들어간 현재 실적을 과거 기사로 오인하지 않도록 수정했습니다. 실제 과거 발표를 회고하는 일반 기사는 계속 제외합니다.
- FOMC 의사록·경제전망을 별도 사건으로 구분합니다. 이전 금리 결정과 묶여 사라지지 않도록 했습니다.
- 월별 발표에 같은 주소를 쓰는 Census 등은 발표별 ID를 사용합니다. 동일 발표의 재수집과 매체 간 중복은 계속 차단합니다.
- 시각이 공개되지 않은 발표는 날짜만 표시합니다. 대만 달러 등 외화 접두어를 달러 환산 과정에서 바꾸지 않습니다.
- 이미지 형식이 확정적으로 거부되면 사진을 제외하고 재시도하고, 필요하면 텍스트로 보냅니다. 결과가 불명확한 전송은 자동 재시도하지 않습니다.

## 발표 누락 감시

현재는 **Census 공식 일정에서 해석 가능한 발표**에 적용합니다. 발표 예정 후 30분이 지났는데 수집 기록이 없으면 확인 알림을 한 번 보냅니다. 공식 발표 지연과 수집 오류를 구분하지 못한 상태이므로 숫자나 발표 내용을 만들어내지 않습니다. 수집 작업이 진행 중이면 확인을 미룹니다. 공식 일정에서 삭제된 항목은 취소 처리합니다.

BLS 일정 페이지는 이 환경의 자동 접근이 거부되어 연결하지 않았습니다. BLS 지표 RSS는 별도로 동작합니다. 다른 기관까지 일정 대조가 되는 것은 아닙니다.

## 범위와 한계

- 직접 뉴스룸 연결은 위 7개 회사입니다. 관심 종목 전체의 모든 IR 페이지를 연결했다는 뜻은 아닙니다. 다른 회사는 기존 SEC·Finnhub 경로가 남아 있습니다.
- 확인했던 Microsoft·ASML·Broadcom 직접 피드는 자동 접근이 거부되었습니다. Micron의 시험한 RSS 주소는 404였습니다. 실패한 주소를 정상 수집처로 등록하지 않았습니다.
- 공식 웹사이트가 RSS를 늦게 갱신하거나 접근을 제한하면 지연될 수 있습니다. 접속 성공과 새 발표 유무를 구분해 최근 공식 발표 시각을 수집 상태에 보관합니다.
- 새 출처의 첫 실행은 최근 24시간만 소급합니다. 기존 기준점과 전송 상태를 초기화하지 않습니다.
- 새 경제지표 형식은 검증된 숫자 서식이 없으면 원문 발췌로 표시합니다. 한국어 숫자 요약을 임의로 만들어내지 않습니다.

## 확인 명령

```powershell
.\.venv\Scripts\python.exe scripts/check_official_sources.py --output data/official-source-check.json
.\.venv\Scripts\python.exe main.py --status
```

첫 명령은 읽기 전용으로 접속과 최근 발표 분류를 검사합니다. 운영 중에도 실행할 수 있으며 Telegram을 보내지 않습니다. 상시 실행을 멈춘 상태에서는 `main.py --official-only --once`로 실제 수집·발송을 한 번 수행할 수 있습니다.
