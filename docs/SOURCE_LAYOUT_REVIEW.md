# 수집 데이터 분석과 알림 구조 시안

2026-10-22 기준. 운영 DB를 읽기 전용으로 분석했다. 본 채널에는 적용하지 않았다.

## 분석 범위

저장된 승인 이벤트 94건(2026-10-13~22 한국시간), 검토 후보 63건, 관측 해시 7,366개를 확인했다. 승인 이벤트의 출처 표기는 14종이다. 탈락한 일반 기사는 원문 대신 해시·이유별 건수만 남으므로, 과거 전체 입력 원문을 분석한 결과로 해석하면 안 된다. 검토 후보 수도 보존 기간과 저장 상한의 영향을 받는다.

## 실제로 확인한 문제

- 이벤트 92: 테슬라 실적 공시의 Item 2.02보다 Roadster 소개가 먼저 선택되어 제품 발표로 분류됐다. 새 시안은 공시 메타데이터를 우선한다.
- 이벤트 90·91·92: 실적표, 첨부파일 이름, 법률 문구가 문장 요약에 섞인다. 평문 표에서 숫자를 임의로 골라 현재 분기 실적으로 사용하지 않는다.
- 이벤트 80: 기사 광고인 “Our AI portfolio … 118%”가 저장된 요약에 포함됐다. 새 시안은 광고를 제외하고 변경 전·후 전망 범위를 분리한다.
- 이벤트 83·94: 금액 범위·날짜·연도의 번역 순서가 부자연스럽다. 새 번역은 숫자·부호·순서 검증을 통과할 때만 사용하고, 실패하면 원문으로 표시한다.
- 이벤트 37: 통신사 요금제와 보상판매 문구가 제품 요약에 포함됐다. 제거 후 본문이 부족하면 원문 확인 안내를 표시한다.
- 이벤트 28: 할인율 회의록은 FOMC 의사록과 구분해야 한다. 이벤트 29는 연설이며 금리 결정이 아니다.
- 이벤트 58: 주택착공 수치는 계절조정 연율이며, -5.2%와 함께 ±11.8% 오차 및 수정치가 있다. 숫자만 강조하면 중요한 조건이 사라진다.
- 이벤트 16: TSMC의 NT$ 기준 EPS와 US$ 기준 ADR 수치가 다르다. 통화·주식 단위를 유지한다.

## 편집 원칙

1. API별로 입력을 정리하되, 최종 카드는 사건 종류에 맞춘다. 같은 Finnhub에서도 실적·전망·인수·시장 동향은 구성이 달라야 한다.
2. 회사명(티커)을 표시한다. 여러 회사가 등장하는 기사는 임의의 한 회사를 발표 주체로 삼지 않는다.
3. 확정 실적, 회사의 잠정 전망, 언론/분석가 주장, 시장 반응을 구분한다. 제목만으로 주장 내용을 확정 사실로 바꾸지 않는다.
4. 한 문장에 현재값·비교값이 함께 있으면 관계를 보존한다. 통화, GAAP/non-GAAP, 희석 EPS/ADR, 전월/전년, 연율, 수정치, 오차범위를 유지한다.
5. 텔레그램에서는 표 대신 짧은 제목·굵은 소제목·항목별 줄바꿈을 사용한다. 정보가 없는 구역은 생략한다.
6. 사진보다 사실과 수치 가독성을 우선한다. 이번 시안은 텍스트 카드로 비교한다.
7. 출처·발표 시각·원문 링크를 하단에 둔다. 날짜만 제공된 자료에 임의 시각을 붙이지 않는다.

## 구현과 현재 한계

`notifications/preview_layout.py`는 운영 경로에서 import하지 않는 별도 시안 모듈이다. `scripts/review_source_layouts.py`가 승인 이벤트 94건을 재구성한다. 운영 DB에는 쓰지 않으며, 발송 옵션은 별도 테스트 채널만 사용한다. 각 성공 발송은 `receipts.jsonl`에 기록한다. 자동 재발송은 하지 않는다.

자동 구조화 가능한 사례부터 구현했다. TSMC 서술형 실적, 변경 전·후 전망 범위, BLS 주요 지표, Census 주택착공, DOL 청구, EIA 가공 수치 등을 처리한다. TSMC 템플릿은 해당 기관의 명확한 통화·항목 패턴만 허용한다. 다른 회사에 통화나 회계 기간을 추정해 적용하지 않는다.

일반 SEC 실적표 파서는 아직 구현되지 않았다. 테슬라 상세 실적 시안은 앞서 만든 특정 공시용 검증 추출기를 유지한다. 다른 SEC 자료에서 표 구조가 소실된 경우 숫자표를 숨기고 구조화 미완료를 표시한다. 한국어 번역 검증 실패 시 일부 영어가 남는다. 이는 다음 단계에서 기간·통화·수치 관계를 구조 필드로 분리해 개선할 대상이다.

새 분류는 미리보기용이며, 기존 필터의 과거 오탐과 누락을 모두 수정한 것은 아니다. 뉴스룸 라이프스타일 기사와 전망 기사의 승인 여부도 별도 필터 검토 대상이다.

## 재현

```powershell
# 모든 저장 이벤트 분석·로컬 카드 생성 (발송 없음)
.\.venv\Scripts\python.exe scripts/review_source_layouts.py
# 선택 사례 번역·로컬 확인 (발송 없음)
.\.venv\Scripts\python.exe scripts/review_source_layouts.py --translate-ids 16 29 34 57 58 80 86
# 검토된 사례를 테스트 채널에 발송
.\.venv\Scripts\python.exe scripts/review_source_layouts.py --send-ids 16 29 34 57 58 80 86
```

분석 JSON과 94개 카드: `data/source-layout-review/`. 본 서비스 적용은 사용자 요청 이후 진행한다.
