# 퀄컴 알림 번역 실패 분석 (2026-10-23)

- 대상: event 100, 본 채널 메시지 19. 2026-10-22 22:10:09 KST 발송.
- 원문: Qualcomm Schedules Fourth Quarter and Fiscal 2026 Earnings Release and Conference Call.
- 로그: `protected_value_changed` 후 영어 원문 발송. 저장된 한국어 제목·본문·번역 해시는 빈 값.

## 재현한 직접 원인

Azure API는 HTTP 200으로 정상 응답했다. 첫 발췌에는 웹페이지 헤더의 `10/22/2026`과 보도자료 날짜의 `Oct.`가 같이 들어 있었다. Azure가 `Oct.`를 `10월`로 번역하자 기존 숫자 검증기가 보호된 숫자 `10`의 출현 횟수가 하나 늘었다고 판단했다. 원문 숫자의 손실이나 실제 금액 변경은 없었다. 한 문장 검증 실패로 번역 전체를 버린 뒤 영어를 발송하는 기존 fallback이 동작했으며 번역 재시도는 하지 않았다. GPU/Ollama와는 무관한 운영 Azure 경로 문제다.

## 함께 확인한 문제 및 수정

1. 숫자 인접 월 이름·월 약어도 번역 보호 토큰에 포함하고 검증 후 한국어 월 표기로 변환한다. `1:45 p.m.` 역시 하나의 토큰으로 보호해 숫자 순서 변경을 방지한다. 금액·반복 숫자 검증은 유지한다.
2. 날짜의 `Oct.`와 시각의 `p.m.` 뒤에서 문장이 끊기지 않도록 한다.
3. PRNewswire `.xn-content` 기사 영역을 우선해 웹페이지 제어 문구를 제외하고 회사 소개 이전까지만 읽는다.
4. `Schedules ... Earnings Release and Conference Call`은 실적 결과가 아닌 실적 발표 일정이다. 제목 분류에서 일정 판정을 어닝콜·실적 결과 판정보다 우선한다.

수정 전 실제 API 재현에서 원인 확인, 수정 후 실제 API 재호출에서 번역 성공 확인. 금액 변조·반복 숫자 손실 등 기존 실패 검증 테스트와 신규 날짜·시각·일정 분류 테스트를 통과했다. 진단 자료와 수정 시안은 `data/qualcomm-review/`에 보관한다. 본 채널 메시지 19는 이번 분석 작업에서 편집·삭제·재전송하지 않았다.
