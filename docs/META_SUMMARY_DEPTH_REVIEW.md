# 메타 실적·어닝콜 요약 누락 점검 (2026-10-22)

## 후속 적용: 고정 문장 수 제한 제거

사용자 요청에 따라 운영 발췌의 4문장·2,400자 제한을 제거했다. 중요도 근거가 있는 서로 다른 문장을 모두 후보에 유지하며 중복과 홍보 문구를 제외한다. 기사 본문 추출은 회사 소개·투자 권유 등 후속 영역 이전에서 종료한다. 중요 이벤트의 확보한 본문을 새 `events.body` 열에 보관한다(기존 데이터는 빈 문자열로 호환). 일반 뉴스 폐기 정책은 그대로다. 기존의 잃어버린 본문은 재수집 없이 복원하지 않는다.

긴 번역은 요청 단위로 나누고, 긴 알림도 Telegram 길이에 맞춰 나눈다. 일부 메시지가 이미 전달된 뒤 실패하면 전체 알림을 자동 재전송하지 않고 결과 불확실 상태로 보류한다. 로컬 LLM 테스트 경로도 상세 3개 제한 및 15,000자 입력 절단을 제거했으며 긴 입력은 구간별로 처리하고 모든 구간의 근거 있는 결과를 합친다. 모델 출력이 토큰 한도로 중단되면 성공으로 처리하지 않는다.

운영은 규칙 기반 중요 내용 발췌와 Azure 번역을 계속 사용한다. 로컬 LLM은 테스트 경로이며 이번 변경으로 자동 대본 수집이나 운영 LLM 분석이 활성화되지는 않는다. 고정된 개수로 자르는 문제는 해소했지만, 규칙 기반 선별이 모든 중요 사실을 의미적으로 보장하는 것은 아니다.

## 확인 결과

기존 메타 어닝콜 카드는 대본을 직접 분석한 결과가 아니다. event 94의 원문은 MarketBeat 어닝콜 하이라이트 기사이며, 저장된 `article_summary`는 4문장이다. `data/ollama-preview/event-94.json`의 LLM 입력도 제목과 이 4문장뿐이었다. 기사 전체나 공식 대본을 읽었다고 볼 수 없다.

1. `notifications/article.py`는 기사 본문을 읽은 뒤 `prepare_brief`를 호출한다.
2. `processors/briefing.py`의 `select_points`는 최대 4문장·2,400자로 축소하고 `prepare_brief`가 `article_summary`를 덮어쓴다. 재호출해도 이미 제외한 정보를 복원할 수 없다.
3. 문장 점수는 수치·행동 단어·문장 위치 등을 사용한다. 주제별 필수 정보나 CEO/CFO 발언, Q&A의 중요도를 따로 확보하지 않는다.
4. 실험용 `ollama_preview.py`의 프롬프트와 JSON 스키마는 상세를 최대 3개로 제한한다. 해당 실행은 실제로 매출 전망과 순이익/EPS 2개만 생성했다.
5. 최근 발송용 `send_recent_compact.py`는 검토된 고정 문구로 편집한 카드다. 경영진 발언 1개·전망 2개의 길이는 원문 전체의 정보량을 나타내지 않는다. GPU 성능이나 응답 타임아웃으로 잘린 결과도 아니다.

## 다시 확보한 자료

- 기존 MarketBeat 기사를 다시 읽어 광고 지표, 비용, 현금흐름, Muse 사용 현황, 가이던스 등 추가 내용 확인.
- 회사 공식 2026년 3분기 어닝콜 PDF 20쪽을 읽고 경영진 발표와 Q&A 전체 검토.
- SEC EX-99.1 실적 발표 첨부자료를 별도로 확보해 표의 연도·단위·서술 수치 검증.
- 원문과 추출 텍스트, 테스트 카드 및 항목별 원문 근거: `data/meta-review/` (로컬 보관).

## 제안 구조

실적 발표: 핵심 변화 → 매출·이익·EPS·마진 → 일회성 비용 등 해석에 필요한 조정 → 설비투자·현금흐름 → 가이던스 → 중요한 주주 사항. 없는 항목은 생성하지 않는다. 비교 기간, 통화, GAAP와 회사 제시 조정치를 유지한다.

어닝콜: 핵심 변화 → 필요한 실적 재확인 → 성장 근거와 경영진 설명 → 중요한 Q&A → 전망·제약. 제품명 나열, 홍보성 문장, 개별 고객 성공담, 반복 발언은 생략한다. 목표·예상과 확정 실적을 구분한다. 질문자의 가정을 회사 답변처럼 쓰지 않는다.

자동화 개선 시에는 원문 전체를 보존하고, 실적/어닝콜 전용 후보 추출을 일반 뉴스의 4문장 제한 이전에 수행해야 한다. 주제별 후보에 원문 근거·화자·기간·수치·공식/기사 구분을 붙여 선별하고, 짧은 기사에는 분량을 강제로 채우지 않는다. 긴 대본은 구간별 후보를 추출한 뒤 전체에서 중복 제거 및 중요도 선별을 수행한다. 항목 수만 늘린 프롬프트에 이미 축소된 4문장을 넣는 것으로는 해결되지 않는다.

이번 작업은 원인 분석과 근거 검토를 거친 테스트 시안 2건이다. 자동 수집·LLM 파이프라인의 원문 보존 및 전용 요약기는 아직 변경하지 않았다. 본 채널의 기존 메시지나 운영 설정도 변경하지 않는다. 공식 대본을 직접 사용한 새 시안의 제목은 `어닝콜 요약`이며, 기존 기사 카드의 제목은 `어닝콜 관련 보도`가 맞다.
